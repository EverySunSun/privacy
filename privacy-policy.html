1. 概述1. Overview

Timestamp Converter 是一款浏览器扩展，用于在 Unix 时间戳与可读日期时间之间互相转换。 所有功能（当前时间戳显示、时间戳转日期、日期转时间戳、时区换算）均在您的浏览器本地完成。

Timestamp Converter is a browser extension that converts between Unix timestamps and human-readable dates. All features (live timestamp, timestamp-to-date, date-to-timestamp, and time-zone conversion) run entirely on your device, inside your browser.

3. 权限说明3. Permission Usage

本扩展仅申请一项权限：

The extension requests exactly one permission:

  • clipboardWrite — 仅用于将转换结果复制到系统剪贴板（写入）。该权限只能写入、不能读取剪贴板，也不用于其他任何用途。 used only to copy conversion results into the system clipboard (write-only). This permission can write but not read the clipboard, and is not used for any other purpose.

本扩展不申请任何主机权限（host permission），也不加载任何远程代码。

The extension requests no host permissions and loads no remote code.

4. 本地处理与网络请求4. Local Processing & Network

所有转换计算均在浏览器本地执行。扩展在运行过程中不会发起任何网络请求， 不会连接任何服务器，也不会与外部服务通信。您的数据永远不会离开您的设备。

All conversions are performed locally in your browser. The extension makes no network requests at any time, connects to no servers, and communicates with no external services. Your data never leaves your device.
